# Sets and Venn Diagrams Using Real-World Data

### Math 140 – Math for Elementary Teachers

This data science module uses real-world data to help students understand sets and Venn diagrams. Students begin by organizing a small sample of data by hand and then use Microsoft Excel to filter and analyze a larger dataset.

The activity progresses from two-set to three-set Venn diagrams and gives students practice interpreting unions, intersections, and complements. Students also complete an independent Venn diagram application without Excel.

## Data Source

The dataset used in this module was adapted for instructional purposes from data published by:

Holmquist, Anna J.; Markelz, R. J. Cody; Martinez, Ciera C.; Gillespie, Rosemary G. (2024). *COI metabarcoding data from arthropod pollinator communities in burned and unburned sites of California*. Dryad.

DOI: 10.5061/dryad.fttdz090v
